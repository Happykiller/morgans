# HTTP Scenarios

Ready-to-run GraphQL HTTP requests are split by scenario:

- `health.http` — health and system queries
- `bulk.http` — bulk job creation and job tracking
- `raw-mail.http` — raw HTML/text email send
- `welcome.http` — generic welcome templates and FitDesk welcome templates
- `fitdesk-plan.http` — FitDesk plan upgrade/downgrade scenarios
- `fitdesk-invitations.http` — FitDesk invitation and acceptance/decline scenarios
